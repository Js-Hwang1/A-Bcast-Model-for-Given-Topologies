# SimGrid Broadcast Experiments

Continuous-time MPI simulations of broadcast algorithms on structured network
topologies, using [SimGrid](https://simgrid.org/) SMPI.

## Purpose

Our discrete-time Python models (in `Topology/`) assume unit-cost communication
steps.  These SimGrid experiments validate those models against realistic
continuous-time physics — per-link bandwidth sharing, latency floors, and
protocol overheads — to determine which algorithmic ideas survive contact with
real network dynamics.

### Network Model: CM02

We use `--cfg=network/model:CM02` for all primary results.  CM02 models each
physical link independently with max-min fair bandwidth allocation.  This is
critical for mesh topologies where multi-hop routes share intermediate links —
the default SMPI model assumes a fat-tree (single shared bottleneck) and does
not penalize multi-hop contention.

### MPI\_Bcast Baseline

SimGrid's default `MPI_Bcast` implementation uses a **binomial tree** algorithm
unconditionally (`bcast__binomial_tree`), with no message-size-based selection
and no topology awareness.  This is confirmed by SimGrid's source
([`smpi_default_selector.cpp`](https://github.com/simgrid/simgrid/blob/master/src/smpi/colls/smpi_default_selector.cpp)):

```cpp
int bcast__default(...) {
    return bcast__binomial_tree(...);
}
```

The binomial tree is constructed from MPI rank numbering, ignoring the physical
topology entirely.  On a mesh, this creates multi-hop routes that contend for
shared links.  Our topology-aware algorithms exploit mesh structure to avoid
this contention.

SimGrid also provides alternative bcast selectors (`--cfg=smpi/bcast:<algo>`)
including `ompi`, `mpich`, and `mvapich2`, which apply message-size heuristics.
We benchmark against the default to establish a clean baseline; production MPI
libraries may perform differently.

## Topologies

### 2D Mesh (`2Dmesh/`)

A P x Q grid with 4-connectivity (left, right, up, down).  Row-major node
numbering: `node_id = row * Q + col`.

Tested configurations:

| Mesh  | Nodes | Links | BFS Depth (corner) |
|-------|------:|------:|-------------------:|
| 4x4   |    16 |    24 |                  6 |
| 10x10 |   100 |   180 |                 18 |
| 25x25 |   625 | 1,200 |                 48 |

Platform XML and hostfiles are generated by `gen_platform.py`.

### 16K3 (`16K3/`)

16-node Kautz graph of degree 3.  Fixed platform.

### Adding a New Topology

1. Create a subdirectory (e.g., `3Dmesh/`).
2. Write or adapt `gen_platform.py` for the new topology.
3. Implement `init_topology()` in the C source to compute adjacency from
   compile-time parameters.
4. Build with appropriate `-D` flags (e.g., `-DROWS=P -DCOLS=Q -DDEPTH=R`).

## Algorithms

### 1. `mpi` — MPI\_Bcast (Baseline)

A single `MPI_Bcast()` call.  We pass the buffer, size, and root — nothing
else is configurable.  SimGrid's internal algorithm (binomial tree) handles
everything.  This is the baseline that all other algorithms aim to beat.

### 2. `greedy` — Greedy Pipelined Broadcast

**Schedule-based, full-duplex.**

Pre-computes a round-by-round schedule offline (not timed), then replays it
with `MPI_Isend`/`MPI_Irecv` + per-round `MPI_Waitall`.

Each round: enumerate all neighbor pairs where the sender has a chunk the
receiver lacks, shuffle deterministically, greedily select non-conflicting
pairs (full-duplex: each node sends to at most one neighbor and receives from
at most one neighbor per round).

Chunk selection: smallest chunk ID that sender has but receiver lacks.

### 3. `bbs` — BBS Frame-Based Broadcast

**Schedule-based, half-duplex.**

Uses pre-computed directed-matching frames from the Python BBS pipeline
(`Topology/2Dmesh/BBS.py`):

1. Limitation matrix (integer edge weights for optimal broadcast)
2. Wavefront frame generation (8 vertex-disjoint directed matchings)
3. Urgency-based frame ordering
4. Edge-swap optimization

Frames cycle round-robin.  Half-duplex: each node appears at most once per
frame (as sender OR receiver, never both).  Zero bandwidth contention by
construction — every transfer is pre-resolved.

**Limitation:** Frame data is topology- and root-specific.  Currently only
generated for 4x4 mesh, root=0.  Use `extract_bbs_frames.py` to generate
frames for other configurations.

### 4. `tree` — Topology-Aware BFS Tree Pipeline

**Async pipelined, full-duplex, no round synchronization.**

1. Build a BFS spanning tree from the root over the mesh adjacency at runtime.
   Every tree edge is a direct mesh link (1-hop, zero link contention).
2. Pipeline K chunks down the tree:
   - **Root:** `MPI_Isend` each chunk to all children, per-chunk `MPI_Waitall`
     (prevents link flooding).
   - **Interior:** Blocking `MPI_Recv` from parent, then `MPI_Isend` to
     children (Recv naturally paces the node — no per-chunk Waitall needed).
   - **Leaf:** Blocking `MPI_Recv` from parent.
3. No round synchronization.  Total time ~= (K + depth) x chunk\_time.

Key advantages over `mpi` baseline:
- All tree edges are 1-hop (zero multi-hop contention)
- Async pipelining (no global barriers between chunks)
- Adapts to any root position (BFS tree computed at runtime)
- Consistent performance across symmetric root positions

## Building and Running

```bash
cd SimGrid/2Dmesh/

# Build for a specific mesh size
make ROWS=4 COLS=4          # default
make ROWS=10 COLS=10        # override

# Generate platform XML + hostfile
make gen                    # uses current ROWS x COLS
python3 gen_platform.py 10 10   # or directly

# Run individual algorithms
make run-mpi   ROOT=0 MSG=67108864
make run-tree  ROOT=0 MSG=67108864 CHUNKS=32
make run-greedy ROOT=0 MSG=67108864 CHUNKS=64

# Head-to-head comparison
make run-compare

# Full sweep across message sizes and roots
./run_experiments.sh              # root=0 only
./run_experiments.sh all          # all roots
./run_experiments.sh 0 5 10 15    # specific roots
```

To build for non-default mesh sizes, pass dimensions at compile time:

```bash
smpicc -O2 -DROWS=10 -DCOLS=10 -o bcast_10x10 bcast_2dmesh.c -lm
smpirun -np 100 -platform platform_2dmesh_10x10.xml -hostfile hostfile_10x10 \
    --cfg=smpi/host-speed:2000Gf --cfg=network/model:CM02 \
    ./bcast_10x10 tree 67108864 32 0
```
