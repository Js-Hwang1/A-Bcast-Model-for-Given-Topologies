Q1 — npn=2 special case: The N=128 dragonfly has npn=2 (only 2 nodes per router). With 2 nodes, the node-level tree is just root→leaf — both T1 and T2 are identical, so no anti-correlation is possible at this level. The example uses 4 nodes. Should this algorithm target npn=4 (N=256), or should npn=2 be handled as a degenerate case where node-level trees collapse to the same single edge?


A1. What is npn? If you mean as (“nodes per router”) yes, N=128 is a special case where you do just (root -> leaf), and this special case does not contradict the general algorithm because anticorrelation is only required for nodes that are neither root nor leaf,but in this case there is no such nodes so you are fine. But the general case is when you would need the two trees (where npn=4).
