# ==============================================================================
# Topology Network Parameter References

# This file documents the references used to determine the network
# configurations (bandwidth, latency, topology structure) for each

# ==============================================================================
# 1. FAT-TREE — InfiniBand EDR (100 Gbps)
# ==============================================================================
#
# Modeled after: ORNL Summit / LLNL Sierra
# Structure: 2-level non-blocking fat-tree (compute → leaf → spine)
#
# Bandwidth: 12.5 GBps (= 100 Gbps / 8, theoretical peak per 4x EDR port)
#   - Mellanox ConnectX-5 HCA, SB7800 Switch-IB 2 switches
#   - Measured throughput: ~12.4 GB/s (64b/66b encoding overhead < 1%)
#   - Source: Mellanox SB7800 datasheet; Dell/Mellanox EDR white paper
#
# Latency: 100 ns per link
#   - SB7800 switch port-to-port latency: 90 ns (datasheet)
#   - 100 ns rounds up slightly to account for wire/connector propagation
#   - End-to-end MPI latency (host-to-host): ~610 ns, but SimGrid's SMPI
#     layer models NIC/software stack overhead separately
#   - Source: Mellanox SB7800 datasheet; OFA Workshop 2015 benchmarks
#
# Real systems:
#   - Summit (ORNL): 4,608 nodes, dual-rail EDR, non-blocking fat-tree
#   - Sierra (LLNL): 4,320 nodes, EDR fat-tree
#

# ==============================================================================
# 3. DRAGONFLY — Cray Aries (XC30/XC40/XC50)
# ==============================================================================
#
# Modeled after: Cray XC40 (Theta, Piz Daint) / XC50 (Piz Daint GPU)
# Structure: hierarchical dragonfly with 3 link tiers
#   - Groups (G) containing chassis (C) containing routers (R)
#   - Each router connects to P compute nodes
#
# Bandwidth: 5.25 GBps per link (all tiers)
#   - Aries ASIC: 40 network ports + 8 NIC ports, 500 GB/s total capacity
#   - Per-link rate: 4.7–5.25 GB/s per direction (we use upper bound)
#   - Source: Cray XC Series Network white paper (ALCF)
#
# Latency (differentiated by tier — realistic for zone-based XML):
#   - Green (intra-chassis): 100 ns — electrical backplane traces
#   - Black (inter-chassis): 200 ns — copper cables within cabinet group
#   - Blue (inter-group):    400 ns — optical fiber, meters to tens of meters
#   - Per-hop switch latency from Cray docs: ~100 ns
#   - Added propagation: copper ~5 ns/m, optical ~5 ns/m
#   - Inter-chassis cables: ~1-2m → +10-20 ns → rounded to 200 ns total
#   - Inter-group fiber: ~10-50m → +50-250 ns → rounded to 400 ns total
#   - Source: Cray XC Network white paper; ALCF Aries network guide
#
# Real systems:
#   - Theta (ALCF/Argonne): 4,392 KNL nodes, XC40, Aries dragonfly
#   - Piz Daint (CSCS): 5,704 nodes, XC50, Aries dragonfly
#   - Cori (NERSC): 9,688 KNL nodes, XC40, Aries dragonfly
#   - Trinity (LANL): XC40, Aries dragonfly
#

# 4. 2D MESH — InfiniBand NDR 400 (400 Gbps)
# ==============================================================================
#
# Modeled after: NVIDIA Quantum-2 NDR InfiniBand fabric
# Structure: P x Q 2D mesh with nearest-neighbor links
#
# Bandwidth: 50 GBps (= 400 Gbps / 8, theoretical peak per NDR port)
#   - NVIDIA ConnectX-7 HCA, Quantum-2 QM9700 switches
#   - 100 Gbps/lane x 4 lanes = 400 Gbps per port
#   - After 64b/66b encoding: ~48.5 GB/s effective
#   - We use 50 GBps (theoretical peak, standard simulation convention)
#   - Source: NVIDIA NDR architecture brochure; QM9700 datasheet
#
# Latency: 100 ns per link
#   - Quantum-2 switch port-to-port: ~90 ns (same or better than HDR)
#   - HDR Quantum QM8790: sub-90 ns (datasheet)
#   - 100 ns rounds up slightly, consistent with other topologies
#   - Source: NVIDIA Quantum-2 datasheet; QM8790 datasheet
#
# Real systems:
#   - Eos (NVIDIA): 576 DGX H100, Quantum-2 NDR fabric
#   - DGX SuperPOD (H100-based): NVIDIA reference architecture
#   - Alps (CSCS): HPE Cray EX, Slingshot-11 (similar generation)
#
